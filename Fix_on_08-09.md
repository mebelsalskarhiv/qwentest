## 📍 Текущий статус проекта

### ✅ Завершённые работы (Фазы 0-3)

#### Фаза 0: Безопасность — 100%
- **HR, Users, Inventory API:** Полная защита RBAC + tenant isolation.
- **Шифрование паролей станций:** Реализовано через Fernet (cryptography).
- **Material Reservations, Work Orders:** Полная защита прав доступа.
- **Исправленные уязвимости:**
  - Утечка данных между тенантами через HR/Users API → **УСТРАНЕНО**.
  - Отсутствие проверки прав доступа (RBAC) → **УСТРАНЕНО**.
  - Пароли станций в открытом виде → **УСТРАНЕНО**.

#### Фаза 1: Производственный домен — 95%
- **Модели данных:**
  - `ProductionOrder` (Заказы на производство)
  - `WorkOrder` (Наряды-заказы)
  - `ProductionStage` (Этапы производства с QC и timeline)
  - `StageTypeDefinition` (Типология этапов)
  - `WorkOrderComment`, `StageTimelineEvent` (Комментарии и аудит)
- **API:** 17 endpoint'ов для управления нарядами и этапами.
- **Связи:** Реализованы связи между заказами, нарядами, этапами и материалами.

#### Фаза 2: Планирование — 100%
- **Модели данных:**
  - `MaterialReservation` (Резервирование материалов)
  - `ResourceCalendar` (Календари ресурсов)
  - `CalendarException`, `WorkShift`, `Holiday` (Смены и исключения)
- **Сервис планирования:**
  - Расчет доступности ресурсов.
  - Поиск свободных слотов.
  - Учет праздников и смен.
- **API:** 6 endpoint'ов (availability, schedule, shifts, holidays).

#### Фаза 3: Качество (ОТК) — 100% (Завершено)
- **Модели данных:**
  - `QualityCheck` (Контроль качества)
  - `DefectType` (Типы дефектов)
  - `CorrectiveAction` (Корректирующие действия / CAPA)
  - `SPCChart` (Карты статистического контроля)
- **Функционал:**
  - Блокировка этапов при выявлении брака.
  - SPC мониторинг процессов.
  - Управление корректирующими действиями.
- **API:** 18 endpoint'ов с полной защитой RBAC.

**Цель:** Реализация модуля оборудования и расчета OEE.

1. **Создание моделей данных:**
   - `Equipment`: Реестр станков и оснастки.
   - `OEELog`: Журнал событий для расчета эффективности.
   - `SensorData`: Сырые данные телеметрии.
   
2. **Реализация логики:**
   - Калькулятор OEE (Availability × Performance × Quality).
   - Сервис агрегации данных телеметрии.

3. **Real-time коммуникация:**
   - Настройка WebSocket канала для стриминга статусов станков.
   - Создание эмулятора ЧПУ (Mock CNC) для генерации тестовых данных.

4. **API:**
   - CRUD для оборудования.
   - Endpoints для получения метрик OEE.
   - WebSocket endpoint для подписки на события.
